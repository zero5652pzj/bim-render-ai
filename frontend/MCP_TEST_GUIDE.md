# MCP 功能测试页面使用指南

## 🌐 **访问方式**

### 方法1：直接URL访问
```
http://localhost:5176/mcp-test
```

### 方法2：通过主页导航
1. 访问主页：`http://localhost:5176`
2. 点击左侧侧边栏中的"**MCP 功能测试**"按钮
3. 自动跳转到测试页面

## 🧪 **测试功能**

### 1. 📊 **MCP 服务器状态**
- 检查服务器是否在线
- 显示服务器信息（名称、版本、协议版本）
- 验证连接状态

### 2. 🛠️ **可用工具列表**
- 获取所有可用的MCP工具
- 显示工具描述和参数说明
- 工具数量统计

### 3. 🌤️ **天气工具测试**
- 输入城市名称（如：北京、Beijing）
- 点击"获取天气"按钮
- 查看返回的天气数据结构

### 4. 💬 **AI聊天测试**
- 支持完整的AI对话
- 自动集成MCP工具调用
- AI会根据问题自动选择合适工具

## 🎯 **测试场景示例**

### 天气查询测试
```
输入：北京天气怎么样？
期望：AI自动调用天气工具返回北京天气信息
```

### 混合查询测试
```
输入：我想设计一座桥，北京今天的天气适合施工吗？
期望：AI先调用天气工具，然后结合天气信息给出施工建议
```

## 🔧 **技术架构**

### 前端集成
- 使用 `@ai-sdk/mcp` 官方客户端
- 支持类型安全的工具定义
- 自动工具发现和调用

### 后端服务
- MCP HTTP传输层
- JSON-RPC 2.0协议
- 支持tools、resources、prompts

### 开发环境
- Vite插件处理API请求
- 热重载支持
- 模拟数据返回
