# 设计文档：删除历史聊天记录功能

## 架构设计

### 前端架构

#### 组件结构

```
MainView.vue
├── 侧边栏
│   ├── 会话列表项
│   │   ├── 对话内容
│   │   └── 删除按钮 (hover 显示)
│   └── 清空历史按钮
├── 聊天区域
│   ├── 消息列表
│   │   ├── 用户消息
│   │   │   └── 删除按钮 (hover 显示)
│   │   └── AI 消息
│   │       └── 删除按钮 (hover 显示)
│   └── 输入框区域
└── 确认对话框组件
```

#### 状态管理

// 新增方法

## UI/UX 设计

### 1. 单个对话删除

#### 位置
- 侧边栏会话列表项的右侧
- 默认隐藏，hover 时显示

#### 视觉设计
- 使用垃圾桶图标（delete-icon）
- 红色主题，表示删除操作
- 图标尺寸：16x16px
- hover 时的动画效果

#### 交互流程
1. 用户 hover 在会话项上
2. 显示删除图标
3. 点击图标
4. 显示确认对话框
5. 用户确认后执行删除
6. 显示成功提示

### 2. 单条消息删除

#### 位置
- 每条消息的右上角
- 默认隐藏，hover 时显示

#### 视觉设计
- 与对话删除相同的图标和颜色
- 较小尺寸：14x14px
- 半透明背景，hover 时不透明

#### 交互流程
1. 用户 hover 在消息气泡上
2. 显示删除图标
3. 点击图标
4. 立即执行删除（可选：显示撤销提示）
5. 消息从列表中移除

### 3. 清空所有历史

#### 位置
- 新建对话按钮下方
- 固定显示，醒目但不抢夺主要按钮注意力

#### 视觉设计
- 使用文本按钮而非图标按钮
- 红色文字，颜色与删除操作保持一致
- 文字："清空所有历史"

#### 交互流程
1. 用户点击"清空所有历史"
2. 显示大型确认对话框
3. 明确说明此操作不可撤销
4. 用户输入"DELETE"确认
5. 执行批量删除
6. 显示进度和最终结果

### 4. 确认对话框设计

#### 单个删除确认对话框

**标题**："确认删除"

**内容**：
```
确定要删除这个对话吗？
此操作将删除对话中的所有消息，且无法恢复。
```

**按钮**：
- 取消（次要按钮）
- 删除（主要按钮，红色）

#### 清空历史确认对话框

**标题**："清空所有历史记录"

**内容**：
```
⚠️ 警告：此操作将删除您的所有对话历史！

此操作将会：
• 删除所有对话
• 删除所有消息
• 无法恢复

如果您确认要继续，请在下方输入：DELETE
```

**输入框**：
- 占位符："请输入 DELETE 确认"
- 验证输入内容

**按钮**：
- 取消（次要按钮）
- 清空历史（主要按钮，红色，禁用直到输入正确）

## 状态管理

### 加载状态

#### 对话删除
- 删除按钮显示 loading 状态
- 整个会话项显示禁用状态
- 禁用期间点击无效

#### 消息删除
- 消息气泡显示淡出动画
- 删除按钮显示 loading
- 动画完成后从 DOM 移除

#### 批量删除
- 整个侧边栏显示遮罩层
- 显示进度条或加载动画
- 显示已删除数量

### 错误处理

#### 网络错误
- 显示错误消息："删除失败，请重试"
- 恢复删除前的状态
- 提供重试按钮

#### 权限错误
- 显示错误消息："无权限执行此操作"
- 引导用户登录或检查权限

## 性能考虑

### 1. 乐观更新
- UI 立即反映删除操作
- 如果后端失败，回滚变更
- 使用 `try-catch` 和错误恢复

### 2. 批量操作优化
- 使用 Supabase 事务确保一致性
- 分批删除大量数据（每批 50 条）
- 显示实时进度

### 3. 内存管理
- 及时从内存中移除已删除项目
- 避免内存泄漏
- 清理事件监听器

## 可访问性

### 键盘导航
- 所有按钮支持 Tab 键导航
- Enter/Space 键触发操作
- ESC 键关闭对话框

### 屏幕阅读器
- 为所有按钮添加 `aria-label`
- 对话框有明确的角色和标签
- 状态变化有适当的通知

### 视觉辅助
- 保持足够的颜色对比度
- 不仅依赖颜色传达信息
- 提供文本标签

## 响应式设计

### 移动端适配
- 删除按钮适当增大（便于触摸）
- 对话框全屏显示
- 优化触摸目标大小（最小 44x44px）

### 平板适配
- 保持桌面端的基本布局
- 适当调整按钮大小
- 优化触摸体验

## 动画与过渡

### 删除动画
- 对话项：从列表中滑动消失
- 消息：淡出 + 向下缩小
- 时长：200-300ms
- 缓动函数：ease-out

### 加载动画
- 按钮：旋转加载指示器
- 对话框：脉冲效果
- 批量操作：进度条动画

## 安全考虑

### 权限验证
- 前端检查用户登录状态
- 后端验证用户权限（RLS 策略）
- 防止跨用户删除

### 软删除机制
- 保持现有软删除实现
- 不实现硬删除
- 数据可通过管理员恢复

### CSRF 防护
- 使用 Supabase 内置保护
- 所有操作需要有效认证
