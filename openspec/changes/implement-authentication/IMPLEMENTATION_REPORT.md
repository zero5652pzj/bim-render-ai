### 关键特性

#### 认证流程
1. **注册**: 邮箱/手机号 + 密码 → 创建账号
2. **登录**: 验证凭据 → 获取 Token → 存储状态
3. **会话管理**: 自动 Token 刷新 → 状态持久化
4. **登出**: 清除状态 → 跳转登录页

#### 安全机制
- JWT Token 自动管理
- RLS 策略保护数据
- API 请求自动认证
- Token 过期自动处理

#### 用户体验
- 响应式设计
- 实时错误提示
